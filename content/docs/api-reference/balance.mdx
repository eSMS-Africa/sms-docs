## GET /api/balance

Get your current wallet balance.

**Auth:** Required

### Response `200`

```json
{
  "balance": 5000.50,
  "currency": "USD",
  "sms_estimate": 4166
}
```

`sms_estimate` is roughly how many single-segment messages the balance covers at your typical route price.

## GET /api/balance/transactions

List your transaction history.

**Auth:** Required

### Query params

| Param | Default | Description |
|-------|---------|-------------|
| `page` | `0` | 0-indexed page |
| `limit` | `20` | 1–100 |

### Response `200`

```json
{
  "transactions": [
    {
      "id": 101,
      "type": "sms_charge",
      "amount": -0.94,
      "balance_after": 4999.56,
      "currency": "USD",
      "description": "SMS to +256712345678 via ESMS_UG (1 seg)",
      "batch_id": null,
      "created_at": "2026-05-02T12:00:01Z"
    },
    {
      "id": 100,
      "type": "credit",
      "amount": 100.00,
      "balance_after": 5000.50,
      "currency": "USD",
      "description": "Wallet top-up",
      "batch_id": null,
      "created_at": "2026-05-01T09:00:00Z"
    }
  ],
  "total": 87,
  "page": 0,
  "limit": 20
}
```

### Transaction types

| `type` | Description |
|--------|-------------|
| `credit` | Wallet top-up |
| `sms_charge` | Charge for a sent message (or bulk batch) |
| `sms_refund` | Automatic refund for a message the gateway rejected |
| `sender_id_fee` / `sender_id_prepaid` | Sender ID registration fee |
| `manual_credit` | Credit applied by support team |
| `manual_debit` | Deduction applied by support team |

Amounts are **negative for charges** and **positive for credits**.

## POST /api/balance/topup

Initiate a wallet top-up via the payment portal.

**Auth:** Required

No request body required.

### Response `200`

```json
{
  "checkout_url": "https://auth.esmsafrica.io/payments/initiate",
  "message": "..."
}
```

`checkout_url` points at the eSMS Africa payment service. The simplest way to top up is to send the user to [sms.esmsafrica.io/payment](https://sms.esmsafrica.io/payment) (card or mobile money). After payment, the credit is applied to the wallet automatically.
