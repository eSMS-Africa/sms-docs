## POST /api/messages/send

Send a single SMS message.

**Auth:** Required

### Request body

```json title="POST /api/messages/send"
{
  "to": "+256712345678",
  "text": "Your OTP is 482910.",
  "sender_id": "MyApp",
  "route": "ESMS_UG"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `to` | string | ✅ | Recipient phone in E.164 format |
| `text` | string | ✅ | Message content |
| `sender_id` | string | - | Approved sender ID. Defaults to route default |
| `route` | string | - | Route code e.g. `ESMS_UG`. Auto-detected if omitted |
| `schedule_mode` | string | - | `"now"` (default) or `"scheduled"` |
| `scheduled_at` | string | If scheduled | ISO 8601 datetime with timezone, 5 minutes to 7 days in the future |
| `international` | boolean | - | Bill the international-delivery rate (USD) for this send. Default `false` |

Send an `Idempotency-Key: <unique-string>` header to make retries safe: a repeat request with the same key returns the original result (with `"idempotent_replay": true`) instead of charging and sending again.

### Response `200`

```json title="Response 200"
{
  "id": "msg-a1b2c3d4",
  "status": "submitted",
  "segments": 1,
  "encoding": "GSM7",
  "recipients": 1,
  "price_per_sms": 35.00,
  "cost": 1.2022,
  "cost_currency": "KES",
  "route_cost": 35.00,
  "route_currency": "UGX",
  "route": "ESMS_UG",
  "balance_after": 1965.00,
  "scheduled_at": null
}
```

When `schedule_mode` is `"scheduled"`, status will be `"scheduled"` and `scheduled_at` will contain the dispatch time. `cost` / `cost_currency` is the wallet deduction. `route_cost` / `route_currency` is the carrier's native price.

### Errors

| Status | Detail |
|--------|--------|
| 400 | Phone cannot be parsed or is missing country code |
| 400 | No active route for this country |
| 400 | `scheduled_at` missing, less than 5 minutes in the future, or more than 7 days out |
| 402 | Wallet balance too low (`insufficient_balance`, with `required` and `available`) |
| 403 | Sender ID not found, not approved, or not approved for this country |
| 403 | Recipient has opted out (`recipient_opted_out`) |
| 409 | Duplicate message within 5 minutes (only when duplicate protection is on) |
| 413 | Message longer than the segment cap (`message_too_long`) |
| 422 | Request body failed validation (missing `to` / `text`) |
| 429 | Rate limit exceeded |

## POST /api/messages/bulk-precheck

Calculate cost of a bulk send before committing.

**Auth:** Required

### Request body

```json
{
  "contact_list_ids": [1, 2],
  "text": "Hi {{name}}, this is a test.",
  "sender_id": "MyApp"
}
```

Instead of `contact_list_ids` you can pass inline `recipients`: `[{"to": "+256712345678", "name": "Amina", "vars": {"code": "X1"}}]`. Set `"international": true` to preview the international-delivery rate.

### Response `200`

```json
{
  "total_contacts": 250,
  "total_segments": 350,
  "total_cost": 1.88,
  "wallet_currency": "USD",
  "wallet_balance": 5000.00,
  "balance_after": 4998.12,
  "sufficient_balance": true,
  "countries": 2,
  "breakdown": [
    {
      "country_code": "UG",
      "country_name": "Uganda",
      "currency": "UGX",
      "route_code": "ESMS_UG",
      "contacts": 150,
      "segments": 200,
      "route_cost": 7000.00,
      "wallet_cost": 1.88,
      "price_per_segment": 35.00
    }
  ],
  "unroutable_count": 1,
  "unroutable": ["+000000000"],
  "suppressed_count": 0
}
```

`suppressed_count` is the number of opted-out (STOP) recipients that were removed.

## POST /api/messages/send-bulk

Send a bulk SMS campaign.

**Auth:** Required

### Request body

```json
{
  "contact_list_ids": [1, 2],
  "text": "Hi {{name}}, your message here.",
  "sender_id": "MyApp",
  "schedule_mode": "now",
  "scheduled_at": null,
  "drip_rate": null
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `contact_list_ids` | array | ✅ (or `recipients`) | List IDs to send to |
| `recipients` | array | ✅ (or `contact_list_ids`) | Inline recipients: `{"to", "name", "vars"}`. Not allowed with `scheduled` |
| `text` | string | ✅ | Message text with optional `{{variables}}` |
| `sender_id` | string | - | Approved sender ID |
| `route` | string | - | Force a specific route |
| `schedule_mode` | string | - | `now` (default), `scheduled`, `drip` |
| `scheduled_at` | string | If scheduled | ISO 8601 UTC datetime |
| `drip_rate` | integer | If drip | Messages per minute |
| `international` | boolean | - | Bill the international-delivery rate (USD). Cannot be combined with `scheduled` |

### Response `200`

```json
{
  "batch_id": "batch-uuid",
  "total_recipients": 250,
  "estimated_cost": 1.88,
  "status": "sending"
}
```

`status` is `sending` (immediate), `scheduled` or `dripping`. Track progress with `GET /api/messages/batch/{batch_id}`.

## GET /api/messages

List messages with pagination and optional status filter.

**Auth:** Required

### Query params

| Param | Default | Description |
|-------|---------|-------------|
| `page` | `0` | 0-indexed page |
| `limit` | `20` | 1–100 |
| `status` | - | Filter: `queued`, `scheduled`, `submitted`, `sent`, `delivered`, `retrying`, `failed` |
| `environment` | `live` | `live`, `test` or `all` (test keys always see test traffic) |
| `to` | - | Filter by recipient phone (E.164) |
| `batch_id` | - | Only messages from this bulk batch |
| `date_from` / `date_to` | - | ISO 8601 bounds on `created_at` |

### Response `200`

```json
{
  "messages": [
    {
      "id": "msg-a1b2c3d4",
      "phone": "+256712345678",
      "text": "Hello",
      "sender_id": "eSMSAfrica",
      "route": "ESMS_UG",
      "country": "UG",
      "segments": 1,
      "encoding": "GSM7",
      "environment": "live",
      "cost": 35.00,
      "currency": "UGX",
      "status": "delivered",
      "error_code": null,
      "retry_count": 0,
      "created_at": "2026-05-02T12:00:00Z",
      "delivered_at": "2026-05-02T12:00:05Z"
    }
  ],
  "total": 150,
  "page": 0,
  "limit": 20
}
```

## POST /api/messages/:message_id/retry

Retry a failed message.

**Auth:** Required

Works on messages whose status is `failed`; any in-flight or delivered message returns `400`. A message whose charge was refunded (or never charged) is billed again before it is re-sent; `402` if the balance is too low. Test (`esms_test_`) messages cannot be retried.

### Response `200`

```json
{
  "id": "msg-a1b2c3d4",
  "status": "submitted",
  "retry_count": 1
}
```
