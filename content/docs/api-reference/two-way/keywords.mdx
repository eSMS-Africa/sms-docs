Each keyword you hold is a **service** with a numeric `service_id`. A service is created
when you request a keyword and moves through `pending` (in review), `active`, `past_due`
(monthly fee unpaid, retried daily), `suspended` (inbound stored, not forwarded), and
finally `cancelled` or `rejected`.

## Get pricing

```
GET https://sms.esmsafrica.io/v1/two-way/pricing
```

Public, no authentication, cacheable for 5 minutes. One row per country where Two-Way SMS
is offered, in USD.

- `availability: "available"` - request it yourself. Currently Nigeria (NG), Ghana (GH),
  Madagascar (MG), Kenya (KE), Uganda (UG), Zambia (ZM), Ethiopia (ET) and
  Cote d'Ivoire (CI).
- `availability: "on_request"` - every other country. Send a request and our team confirms
  availability and pricing. These rows have `null` prices and `is_available: false`.

```json
{
  "currency": "USD",
  "countries": [
    {
      "availability": "available",
      "country_code": "NG",
      "country_name": "Nigeria",
      "setup_fee_usd": 100.0,
      "monthly_fee_usd": 50.0,
      "shared_keyword_monthly_fee_usd": 50.0,
      "inbound_price_usd": 0.0068,
      "outbound_price_usd": 0.0068,
      "sms_basic_price_usd": 0.0068,
      "price_source": "basic",
      "toll_free_available": false,
      "toll_free_inbound_price_usd": null,
      "networks": ["MTN", "Airtel", "Glo", "9mobile"],
      "is_available": true
    }
  ]
}
```

| Field | Description |
|-------|-------------|
| `setup_fee_usd` | One-time setup fee, charged on approval. |
| `shared_keyword_monthly_fee_usd` | Monthly fee for a keyword on a shared code (VAT inclusive). Charged on approval, then every 30 days. |
| `monthly_fee_usd` | Monthly fee for a dedicated code (arranged by sales). |
| `inbound_price_usd` / `outbound_price_usd` | Effective price per inbound / outbound SMS segment. |
| `sms_basic_price_usd` | The country's Basic SMS price, which per-SMS prices follow by default. |
| `price_source` | `basic` (per-SMS prices follow the Basic SMS price) or `custom` (a custom two-way price is set). |
| `toll_free_available` / `toll_free_inbound_price_usd` | Whether toll-free codes are offered, and their inbound price (`null` = same as `inbound_price_usd`). |
| `networks` | Mobile networks served. |

Prices in examples are illustrative; read live values from this endpoint.

## Check a keyword

```
GET https://sms.esmsafrica.io/v1/two-way/keywords/check
```

Whether a keyword is free. Pass `country_code` (free on any shared code in the country) or
`number` (free on that shared code). Keywords are 2 to 20 letters or digits with at least
one letter; STOP, START, HELP, INFO and their synonyms are reserved. Scope: `two_way` or
`query`.

| Parameter | Description |
|-----------|-------------|
| `keyword` | Required. Any case. |
| `country_code` | ISO code, e.g. `NG`. |
| `number` | A shared short code, e.g. `3450`. |

```json
{ "keyword": "CLINIC", "available": true, "reason": null }
```

```json
{ "keyword": "HELP", "available": false, "reason": "HELP is reserved and cannot be used as a keyword" }
```

Other `reason` values: *Already taken on this short code*, *Already taken on every shared
short code in this country*, *Already requested by another customer*, *Keywords must be
2-20 letters or digits (no spaces or symbols)*, *Keywords must contain at least one letter
(numbers alone are reserved for menu replies)*.

## Upload a KYC document

```
POST https://sms.esmsafrica.io/v1/two-way/kyc-documents
```

Upload one file (multipart field `file`): PDF, PNG, JPG or WEBP, up to 5 MB. Pass the
returned `id` in `kyc_document_ids` when you [request a keyword](#request-a-keyword).
Download your own document later with `GET /v1/two-way/kyc-documents/{id}`. Scope:
`two_way`.

```json
{
  "id": 7,
  "filename": "certificate.pdf",
  "content_type": "application/pdf",
  "size": 183204,
  "url": "/api/two-way/kyc-documents/7"
}
```

## Request a keyword

```
POST https://sms.esmsafrica.io/v1/two-way/services
```

Creates a `pending` request for review. **Nothing is charged until it is approved**; then
the setup fee and first month are charged from your wallet. In an `on_request` country the
request is an enquiry (`on_request: true`, KYC optional): our team confirms availability and
pricing first. Scope: `two_way`.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `country_code` | string | Yes | ISO code, e.g. `NG`. |
| `type` | string | Yes | `"shared"` for a keyword on a shared code. (Dedicated codes are arranged by sales.) |
| `keyword` | string | Yes for `shared` | 2 to 20 letters or digits, at least one letter. |
| `number_id` | integer | No | A preferred shared code (`id` from [List countries](#list-countries)). Omit and we assign one. |
| `toll_free` | boolean | No | Toll-free code where offered. Default `false`. |
| `company_name` | string | Yes | 2 to 200 characters. |
| `use_case` | string | Yes | 10 to 4,000 characters. What customers will text and what you will reply, with samples. |
| `kyc_document_ids` | integer[] | Yes, unless `kyc_document_urls` (optional on request) | IDs from [Upload a KYC document](#upload-a-kyc-document). Up to 10. |
| `kyc_document_urls` | string[] | No | Links to documents instead of uploads. Up to 10. |
| `webhook_url` | string | No | Where this keyword's webhooks go (https recommended). |

Returns `201` with the [service object](#the-service-object). Errors:
`409 keyword_unavailable`, `409 duplicate_request`, `422 country_unavailable`,
`422 kyc_required`, `422 invalid_document`, `422 invalid_number`.

## Export messages (CSV)

```
GET https://sms.esmsafrica.io/v1/two-way/services/{service_id}/export.csv
```

Inbound and outbound messages for this keyword, oldest first, up to 50,000 rows. Optional
`since` / `until` (ISO 8601). Columns: `created_at, direction, phone, code, keyword, text,
matched_by, status, segments, billed, cost, message_id`. Scope: `two_way` or `query`.
