## GET /api/webhooks

Get your webhook configuration.

**Auth:** Required (`webhooks` scope)

### Response `200`

```json title="Response 200"
{
  "dlr_url": "https://yourapp.com/webhooks/sms-dlr",
  "mo_url": null,
  "signing_secret": "whsec_abc123...",
  "is_active": true
}
```

---

## PUT /api/webhooks

Update your webhook configuration.

**Auth:** Required (`webhooks` scope)

### Request body

All fields are optional. Omitted fields are unchanged.

```json title="Request body"
{
  "dlr_url": "https://yourapp.com/webhooks/sms-dlr",
  "is_active": true
}
```

| Field | Type | Description |
|-------|------|-------------|
| `dlr_url` | string | URL to receive delivery report callbacks (send `""` to clear) |
| `mo_url` | string | URL for incoming message (MO) callbacks |
| `is_active` | boolean | Enable or disable webhook delivery |

### Response `200`

```json title="Response 200"
{ "status": "updated" }
```

## POST /api/webhooks/test

Send a sample signed `message.delivered` event to your `dlr_url` and a sample `message.inbound` event to your `mo_url`. Returns the result per endpoint, e.g. `{"dlr": {"ok": true, "status": 200}}`. `400` if no URL is configured.

**Auth:** Required (`webhooks` scope)

---

## POST /api/webhooks/rotate-secret

Rotate the HMAC signing secret. Returns the new secret immediately.

**Auth:** Required (`webhooks` scope)

No request body required.

### Response `200`

```json title="Response 200"
{
  "signing_secret": "whsec_newxyz789..."
}
```

Update your webhook handler with the new secret before the old one is removed from your handler. The old secret stops working immediately after rotation.

## DLR webhook payload

The platform sends `POST` requests to your `dlr_url` when a message reaches a terminal state.

```json title="POST to your dlr_url"
{
  "event": "message.delivered",
  "message_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "status": "delivered",
  "phone": "+256712345678",
  "sender_id": "eSMSAfrica",
  "segments": 1,
  "encoding": "GSM7",
  "environment": "live",
  "livemode": true,
  "cost": 35.00,
  "error_code": null,
  "retry_count": 0,
  "delivered_at": "2026-05-02T12:00:05Z",
  "failed_at": null
}
```

**Signature header:** `X-Webhook-Signature: sha256=<hmac_sha256_hex>`

See [Webhooks - signature verification](/docs/delivery/webhooks#signature-verification) for verification examples.

Your endpoint should return a `2xx` within 15 seconds. A failed delivery is retried twice (after ~5s and ~15s). Inspect attempts with `GET /api/webhook-deliveries` and re-send one with `POST /api/webhook-deliveries/{id}/replay`.
