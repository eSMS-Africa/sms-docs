---
title: Real-time Updates (WebSocket)
description: Connect via WebSocket to receive live message status and balance updates.
---

The eSMS Africa platform exposes a WebSocket endpoint that pushes real-time events to connected clients - no polling required.

## Connect

```text title="WebSocket URL"
wss://sms.esmsafrica.io/ws
```

Authentication is via the session cookie (`esms_access_token`), which the browser sends automatically from an authenticated session. You can also pass the session JWT as a `?token=` query parameter. API keys are not accepted on the WebSocket; an unauthenticated connection is refused.

```js title="connect.js"
const ws = new WebSocket("wss://sms.esmsafrica.io/ws");

ws.addEventListener("open", () => {
  console.log("Connected");
});

ws.addEventListener("message", (event) => {
  const data = JSON.parse(event.data);
  console.log(data);
});
```

<Callout>
WebSocket auth uses the same session cookie as the portal. For server-to-server integrations, use [webhooks](/docs/delivery/webhooks) instead.
</Callout>

## Events

### `message_status`

Fired whenever a message reaches a new delivery state.

Every event is a JSON object with a `type` and a `data` payload.

```json title="message_status event"
{
  "type": "message_status",
  "data": {
    "message_id": "msg-a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "status": "delivered",
    "dlr_status": "DELIVRD",
    "updated_at": "2026-05-02T12:00:05Z"
  }
}
```

### `balance_update`

Fired after each successful send, when your balance decreases.

```json title="balance_update event"
{
  "type": "balance_update",
  "data": {
    "balance": 1965.00,
    "currency": "UGX"
  }
}
```

## Keep-alive (ping/pong)

To prevent the connection from being dropped by proxies, send a ping every 30 seconds:

```js title="Keep-alive"
setInterval(() => {
  if (ws.readyState === WebSocket.OPEN) {
    ws.send(JSON.stringify({ type: "ping" }));
  }
}, 30_000);
```

The server responds with:

```json
{ "type": "pong" }
```

## Full example

```js title="websocket.js"
function connectWebSocket() {
  const ws = new WebSocket("wss://sms.esmsafrica.io/ws");

  ws.addEventListener("open", () => {
    console.log("WS connected");
    setInterval(() => ws.send(JSON.stringify({ type: "ping" })), 30_000);
  });

  ws.addEventListener("message", ({ data }) => {
    const event = JSON.parse(data);

    switch (event.type) {
      case "message_status":
        updateMessageRow(event.data.message_id, event.data.status);
        break;
      case "balance_update":
        updateBalanceDisplay(event.data.balance, event.data.currency);
        break;
    }
  });

  ws.addEventListener("close", () => {
    // Reconnect after 3 seconds
    setTimeout(connectWebSocket, 3_000);
  });
}

connectWebSocket();
```
