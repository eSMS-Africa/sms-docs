title: Sender IDs
description: What sender IDs are and how they work across African countries.

A sender ID is the name or number displayed as the "From" field on a recipient's phone when they receive your SMS. Instead of seeing a random number, recipients see your brand name.

## Types of sender IDs

| Type | Example | Notes |
|------|---------|-------|
| Alphanumeric | `MyApp`, `ClinicSMS` | Max 11 characters. Most common for business use. Cannot receive replies. |
| Numeric | `+254712345678` | A real phone number. Can receive replies. |
| Short code | `20880` | Country-specific, requires carrier agreement. |

The eSMS Africa platform primarily uses **alphanumeric sender IDs**.

## Country requirements

Sender ID requirements vary by country. Some require pre-registration with carriers before use.

| Country | Registration required | Notes |
|---------|----------------------|-------|
| Kenya 🇰🇪 | Yes | Must register with carriers. 7–14 day approval. |
| Uganda 🇺🇬 | Yes | Carrier registration required. |
| Nigeria 🇳🇬 | Yes | NCC registration. Business docs required. |
| Ghana 🇬🇭 | Yes | NCA registration. |
| South Africa 🇿🇦 | No network pre-registration | Request your sender ID in the dashboard: default sender IDs are not available here. |
| Tanzania 🇹🇿 | Yes | TCRA registration required. |

<Callout type="warn">
Using an unregistered sender ID in countries that require registration can result in message delivery failure or carrier blocking. Always request a sender ID before launching campaigns in new countries.
</Callout>

## Sender ID pricing

Sender ID fees are stated in USD per country and are independent of top-ups. Your SMS credit
is not used for them. The fee is shown upfront on the request form in the dashboard.

### USD 100 one-time - covers all networks

In every African country except Kenya and Uganda, one flat fee of **USD 100 per country**
registers your sender ID on every network.

A request that covers several countries is charged USD 100 for each of them (Kenya and
Uganda use the bundles below).

### Kenya - one payment covers all networks

One-time, with no monthly maintenance.

| Telkom | One-time | USD 34.66 |
| Equitel | One-time | USD 69.32 |
| **Total** | | **USD 212.57** |

### Uganda - one payment covers all networks

| Network | Calculation | Amount |
|---------|-------------|--------|
| MTN | 3 months x USD 67 | USD 201 |
| Airtel | One-time | USD 67 |
| **Total** | | **USD 268** |

After the first 3 months, MTN is UGX 250,000 per month, charged in USD at the exchange rate at that time. Your SMS credit is not used for it. Nothing is debited automatically: we contact you when it is due.

### Paying the fee

Pay the fee through **Pay for Sender ID**, by mobile money where available, Mukuru or crypto. Your
SMS credit is not used for Sender ID fees. Registration needs the fee paid in full before approval.

- A fee is **one payment**, in full. The amount is fixed to what is due and anything else is refused,
  on every payment method.
- The total shows the processing fee. A mobile money or card checkout may add its own charge, which it
  shows before you confirm and which you pay on top.
- If a country is **not available yet**, we cannot send there today: you can still submit the request,
  you are not charged, and it cannot be paid until the country is available.
- The payment is held on the request and goes to your balance if it is rejected or deleted.

Current fees for all 54 countries are on [esmsafrica.io/pricing](https://esmsafrica.io/pricing)
and from the public [`GET /api/sender-ids/fees`](/docs/api-reference/sender-ids#get-sender-id-fees)
endpoint.

## Default sender IDs

Default sender IDs (`eSMS`, `eSMSAfrica` and each country's route default) can be used only in these 8 countries:
Ghana (`GH`), Uganda (`UG`), Kenya (`KE`), Tanzania (`TZ`), Cote d'Ivoire (`CI`), Rwanda (`RW`), DR Congo (`CD`) and
Nigeria (`NG`). If you don't specify `sender_id` there, the route's default is used.

Everywhere else you must register your own sender ID, because spammers misused the default sender IDs. Only eSMS Africa
can assign a default sender to a specific account.

- A live send with no `sender_id`, or with a default sender, outside those countries returns `403` with code
  `sender_id_required` and a `register_url`. Nothing is charged. Bulk sends return the same code with `countries`.
- Campaigns skip those recipients with reason `sender_id_required` and block at review.
- Test keys (`esms_test_`) still accept the default sender and flag it: `live.sender_approved` is `false` and
  `live.sender_note` says a live send would be refused.
- On verification, an account gets `eSMS` and `eSMSAfrica` only if its home country is one of the 8.

[`GET /api/sender-ids/default`](/docs/api-reference/sender-ids#get-your-default-sender) shows what applies to your account.

## Limits

- Length: 1–11 characters (alphanumeric sender IDs)
- Allowed characters: A–Z, a–z, 0–9, space
- Cannot start or end with a space
- Cannot be a reserved word (e.g., `FREE`, `INFO` in some countries)
